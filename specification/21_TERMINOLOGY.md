# TERMINOLOGY

Document ID: SPEC-021 Version: 1.0 (Draft) Status: Official Draft

Depends On: - SPEC-000 Adjung Constitution - All preceding
specifications

# 1. Purpose

This document establishes the official terminology of Adjung.

Every specification, interface, implementation, and publication should
use these terms consistently.

# 2. Philosophy

Consistent terminology reduces ambiguity and preserves architectural
integrity.

A single concept should have a single preferred term.

# 3. Naming Principles

- Prefer clear over clever.
- Prefer stable over trendy.
- Avoid synonyms for the same concept.
- Use title case for official module names.

# 4. Core Terms

Author  
A person who creates intellectual works.

Publication  
A published knowledge object.

Note  
A concise structured publication.

Essay  
A long-form structured publication.

Folio  
A curated intellectual portfolio.

Biography  
The author’s personal and professional profile.

Editorium  
The editorial environment of Adjung.

Writing Desk  
The primary authoring workspace.

Frontpage  
The main public gateway to the platform.

# 5. Reserved Terms

Reserved names must not be redefined elsewhere without a formal
architectural decision.

# 6. Abbreviations

SPEC - Specification ADR - Architectural Decision Record RBAC -
Role-Based Access Control UI - User Interface API - Application
Programming Interface

# 7. Governance

Changes to official terminology require architectural review to ensure
consistency across the entire specification.
