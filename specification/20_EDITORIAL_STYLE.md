# EDITORIAL STYLE

Document ID: SPEC-020 Version: 1.0 (Draft) Status: Official Draft

Depends On: - SPEC-000 Adjung Constitution - SPEC-007 Publication
Model - SPEC-011 Editorium - SPEC-019 UI System

# 1. Purpose

This document defines the editorial style standards used throughout
Adjung.

The objective is to ensure that publications remain consistent,
readable, professional, and suitable for long-term preservation.

# 2. Editorial Philosophy

Editorial style should improve communication without changing an
author’s meaning or intellectual intent.

Consistency strengthens readability.

# 3. Objectives

The editorial style shall:

- Promote clarity.
- Encourage consistency.
- Preserve author voice.
- Improve accessibility.
- Support high-quality publishing.

# 4. Writing Standards

Authors are encouraged to:

- Use clear language.
- Structure ideas logically.
- Cite sources where appropriate.
- Avoid unnecessary ambiguity.

# 5. Formatting Standards

Editorial guidance covers:

- Headings
- Paragraphs
- Quotations
- Lists
- Tables
- Figures
- Footnotes
- References

# 6. Language

Adjung supports multilingual publishing.

Each publication should clearly identify its primary language.

# 7. Citations

Citation practices should be transparent, consistent, and attributable.

Citation formats may evolve through separate specifications.

# 8. Editorial Consistency

Editorial decisions should remain consistent across publications unless
documented exceptions apply.

# 9. Future Expansion

Future editions may define:

- Style guides by language
- Academic citation styles
- Typography rules
- Accessibility writing guidance
- Inclusive language recommendations
