# Adjung Workspace Custom Rules

- **Italics Rule**: Jangan sesekali italickan mana2 ayat atau perkataan melainkan bersebab (Never italicize any sentence or word unless there is a specific, justified reason).

- **Adjung Brief Boundary Rule**: Adjung Brief ialah Internal Newsroom & Editorial Curation System (bukan platform awam/Adjung Platform). Semua pengguna ialah Editorial Staff / System Admin (CHIEF_EDITOR, SENIOR_EDITOR, EDITOR, RESEARCH_EDITOR, SYSTEM_ADMIN). Tiada Public User, Writer Awam, Member atau Creator Community. Rujukan seni bina wajib berpandukan Canonical Data Model v1.2 Final.
