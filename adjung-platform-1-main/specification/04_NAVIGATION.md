# 1. Purpose

This document defines the navigation philosophy and navigation model of
Adjung. It specifies how users discover, access, and move between
knowledge without prescribing any visual design.

# 2. Navigation Philosophy

Navigation should serve knowledge, not engagement.

Every navigation decision should reduce cognitive load while making the
knowledge structure easier to understand.

# 3. Navigation Goals

- Simple
- Predictable
- Consistent
- Accessible
- Scalable

# 4. Primary Navigation

Primary navigation provides access to the major product areas.

Core destinations include:

- Home
- Discover
- Writing Desk
- Publications
- Folio
- Biography
- Editorium
- Notifications
- Settings

# 5. Secondary Navigation

Secondary navigation is contextual.

Examples include:

- Publication tabs
- Folio sections
- Filters
- Collections
- Search scopes

# 6. Breadcrumbs

Breadcrumbs should be available wherever hierarchical navigation
improves orientation.

# 7. Search as Navigation

Search is considered part of the navigation system rather than a
standalone feature.

Search should allow users to reach any knowledge object directly.

# 8. Navigation Principles

- Never hide important destinations.
- Minimise unnecessary clicks.
- Maintain consistent placement.
- Preserve orientation.
- Avoid navigation dead ends.

# 9. Future Considerations

The navigation system should support future modules without requiring
major structural redesign.
